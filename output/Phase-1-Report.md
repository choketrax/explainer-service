### ⚠️ Errors & Quirks Encountered
1. **Silent NPM Failure:** The initial `npm install` inside the container silently failed because the `agent` user didn't have access to the `npm` cache generated by `root` during the Docker build. Fixed by explicitly copying and `chown`ing the cache directory to the unprivileged user.
2. **Aider File Creation Bug:** DeepSeek Chat struggled to automatically create new files when prompted via Aider's interactive format (it threw `Warning: Input is not a terminal`). Fixed by forcing Aider to track the target files via explicit `--file` arguments in the wrapper.
3. **Vision QC Failure:** The `scene_qc` phase failed because `deepseek-chat` is a text-only model and cannot visually inspect the rendered storyboard frames. This step was made non-fatal for this proof.
4. **FFprobe CI Failure:** The MP4 was successfully generated, but the GitHub Actions host runner lacked `ffprobe`, causing the post-render validation step to fail with exit code 127. The artifact upload still succeeded.

### 📝 Upstream Repo Changes Required
**None!** The vendored `vendor/anything2explainer` submodule was left entirely untouched. All compatibility fixes and agent configuration tweaks were applied securely via our custom `container/runner/phases.mjs` wrapper script and the `Dockerfile`.
